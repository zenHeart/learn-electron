# introduction

Learn about Electron's architecture and process model.

![](/process_model.png)

## Process Model

Electron applications consist of multiple processes:

- **Main Process**: Controls application lifecycle and creates renderer processes
- **Renderer Process**: Displays the UI using Chromium and Node.js
- **Utility Process**: Performs privileged operations in a sandboxed environment

## Key Concepts

- Multi-process architecture
- Inter-process communication (IPC)
- Security considerations
- Process isolation
