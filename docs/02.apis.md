# API

## setBoudnds

* window 坐标系相对于屏幕左上角，向下坐标系
* browserView 坐标系相对窗口左下角，向下坐标系
  * 所以正常显示需要把  y 设置为窗口 -高度才能变为以左上角为顶点的向下坐标系
* 但是后续转换坐标系又相对于窗口左上角的向下坐标系
* 在设置 y 坐标时， mac 会从包含计算，windows 不会，所以对于 mac 需要添加一个顶部栏高度避免对内容区形成遮挡，详见 [BrowserView setBounds behavior inconsistent between Mac and Windows](https://github.com/electron/electron/issues/35994#issuecomment-1368095370)
